Para consolidar os conceitos fundamentais de desenvolvimento em Java, criei uma Lista Interativa de Tarefas executada via console. A proposta do projeto foi construir
uma aplicação simples que permitisse a interação direta com o usuário. O programa recebe novas tarefas pelo terminal, controla a repetição do fluxo perguntando se o 
usuário deseja continuar inserindo itens e, ao final, renderiza a lista completa e organizada com tudo o que foi cadastrado.   Durante o desenvolvimento, pratiquei na prática 
o controle de fluxo usando laços while, a captura de dados via console e a manipulação dinâmica de coleções com a classe ArrayList do Java.   Desenvolvi esse projeto para
exercitar a lógica de programação, a organização do código e o tratamento da entrada de dados, garantindo uma estrutura funcional e bem encadeada.
