# 📋 Lista Interativa de Tarefas

Projeto simples em Java para adicionar tarefas de forma interativa pelo console.

---

## 💡 Sobre

O programa permite que o usuário digite tarefas e escolha se deseja continuar adicionando.

Quando finalizado, todas as tarefas são exibidas em forma de lista.

---

## 🚀 Tecnologias

- Java  
- ArrayList  
- Estrutura de repetição (while)  

---

## 📚 O que pratiquei

- Lógica de programação  
- Entrada de dados pelo console  
- Controle de fluxo com while  
- Manipulação de listas  

---

## ▶️ Como funciona

- Digite uma tarefa  
- Escolha **"s"** para continuar ou **"n"** para finalizar  
- Ao final, a lista completa é exibida  

---

## 🎯 Objetivo

Praticar conceitos básicos de programação e interação com o usuário.
